Framework-agnostic · zero runtime dependencies

Multi-step forms, without the machinery.

Demetria turns a typed JSON schema into a semantic, navigable form. Bring your own visual design and keep control of the browser.

Get startedExplore examples 
npm install demetria

import { createForm } from 'demetria';

const form = createForm({
  target: '#signup',
  schema: {
    id: 'signup',
    steps: [/* your fields */]
  }
});

form.mount();

Focused core

The form flow, not a UI framework

Demetria owns predictable form state, validation, and navigation. Native controls and stable CSS hooks let the host application own presentation.

01 / SCHEMA

Typed definitions

Define steps and six native field types in plain data, with useful TypeScript inference at the integration boundary.

02 / FLOW

Two navigation models

Run all steps on one page, or coordinate real page-to-page navigation while restoring saved values.

03 / ACCESS

Accessible foundations

Semantic controls, error associations, keyboard operation, and managed focus are part of the renderer—not an add-on.
