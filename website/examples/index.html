Integration notes

  • The package ships no CSS. Example styling uses public class hooks and lives in examples/shared.
  • The presentation toggle shows the same generated markup with enhanced or near-native control styling.
  • Optional fields are labeled explicitly. A non-empty optional value is still type-validated.
  • The multi-page example stores only fictional demonstration data. Do not use Web Storage for secrets or sensitive personal data.

For local development, run npm run docs:build and serve site-dist over HTTP. Browser modules do not work reliably when opened directly with file:.
